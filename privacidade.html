Política de Privacidade

Última atualização: 5 de novembro de 2026

1. Quais dados tratamos

Tratamos os dados que você nos informa: (a) no formulário de contato, como nome, e-mail, WhatsApp, cidade, estado e a mensagem enviada; (b) no cadastro de gestor, o e-mail e a senha de acesso; e (c) os dados das competições que o gestor registra, como nomes de equipes, atletas, jogos e resultados.

2. Para que usamos

Usamos os dados de contato para responder ao seu pedido. Os dados de acesso servem para identificar o gestor e permitir que ele edite apenas o que criou. Os dados das competições são exibidos publicamente para consulta de resultados, tabelas e chaveamentos.

3. Dados de atletas e menores

Quem cadastra atletas, em especial menores de idade, é responsável por ter a autorização necessária para a divulgação dos nomes. Recomendamos registrar somente o necessário para a organização da competição.

4. Onde ficam os dados

Os dados ficam armazenados em um banco de dados em nuvem fornecido pelo Supabase, com acesso controlado por permissões. A senha é guardada de forma protegida pelo serviço de autenticação.

5. Compartilhamento

Não vendemos nem compartilhamos dados pessoais com terceiros para fins de marketing. As informações das competições são públicas, por natureza do serviço.

6. Seus direitos

Você pode pedir acesso, correção ou exclusão dos seus dados, e a remoção de nomes de atletas, usando o formulário de contato. Atenderemos ao pedido nos prazos previstos na Lei Geral de Proteção de Dados (Lei 13.709/2018).

7. Alterações

Esta política pode ser atualizada. A data da última atualização aparece no topo desta página.
